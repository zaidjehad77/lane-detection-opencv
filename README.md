# Lane Detection System (Computer Vision)

Computer vision pipeline that detects and tracks road lane lines in images and video for ADAS (Advanced Driver Assistance Systems) applications.

## Tech Stack
Python · OpenCV · NumPy · Matplotlib

## Highlights
- Camera calibration to remove lens distortion.
- Color and gradient thresholding to isolate lane pixels.
- Perspective transformation to a bird's-eye view.
- Lane fitting, curvature calculation, and vehicle offset estimation.
